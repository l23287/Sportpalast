## Kernaussagen (Zusammenfassung Claude)
- **SMART** = **S**pezifisch · **M**essbar · **A**ttraktiv · **R**ealistisch · **T**erminiert. Zurückgeführt auf
  Peter Drucker (1950er, „Management by Objectives“).
- *Spezifisch:* präzise statt vage formulieren. *Messbar:* Erfolg rückblickend feststellbar, ggf. Ersatzgrößen.
  *Attraktiv:* positiv formulieren („Ich möchte …“ statt „Ich will nicht mehr …“). *Realistisch:* herausfordernd,
  aber machbar – Übermut frustriert. *Terminiert:* Deadline als Kontrollpunkt und Ansporn (Goal-Gradient-Effekt).
- Spannungsfeld „attraktiv“ ↔ „realistisch“ erfordert manchmal einen Kompromiss.
- Häufige Fehler: falsche Präzision, unsichtbare Messlatte, blockierender Übermut, fehlende Akzeptanz, keine Limits.
- Empfehlung: **auf maximal drei Kernziele fokussieren**.
- Praxistipps: **Aufschreiben, Visualisieren, Kontrollieren, Anpassen, Feiern**.
- Kritik: zu ergebnisorientiert; Kriterien werden unterschiedlich ausgelegt (kein einheitlicher Standard).
- Alternative: WOOP (Wish, Outcome, Obstacle, Plan); ergänzend W-Fragen.

## Umsetzung in TrainerPro (C09)
| Aussage der Quelle | Umsetzung |
|---|---|
| fünf SMART-Kriterien | SMART-Check mit fünf Kacheln im Zielformular, Tipp zum ersten offenen Kriterium |
| positiv formulieren (Attraktiv) | Verneinungen („nicht“, „kein“, …) lassen „A“ offen |
| Messbar / Ersatzgrößen | eigenes Feld „Woran misst du den Erfolg?“ |
| Realistisch / Realitäts-Check | Selbsteinschätzung per Häkchen |
| Terminiert / Deadline | Zieldatum, Restzeit („noch 10 Tage“), Fortschrittsleiste |
| maximal drei Kernziele | höchstens 3 offene Ziele je Sportart |
| Aufschreiben / Visualisieren | Ziele dauerhaft sichtbar in der Planübersicht |
| Kontrollieren / Anpassen | Restzeit, Hinweis bei Überschreitung „Ziele anzupassen ist kein Scheitern“, Bearbeiten |
| Feiern | Abhaken mit Erfolgsmeldung 🎉, erreichte Ziele bleiben sichtbar |
| Kriterien unterschiedlich auslegbar | Check ist nur Hinweis, blockiert kein Ziel |
